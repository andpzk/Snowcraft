# Snowcraft

This is a mirror of the flash game, which can be found at [http://nny.com/snowcraft/play/](http://nny.com/snowcraft/play/)

The mirrored content comes from [Archive.org](https://archive.org/details/snowcraft_game)

```
Snowcraft, a simple game where the player controls 3 kids who have a snowball fight against computer-controlled teams with ever increasing number of players.
```

***

## Run on Windows 11

No installation or Flash Player is required. Double-click `Play Snowcraft.cmd` in
the project folder. The launcher starts the original game from `EXE/Snowcraft.exe`.

The bundled executable is a Macromedia Director projector, not a Flash movie.

***

## Compatibility

The original 32-bit Director projector has been verified to run natively on
64-bit Windows 11. Windows 11 supports 32-bit desktop applications through
its WoW64 compatibility layer.
